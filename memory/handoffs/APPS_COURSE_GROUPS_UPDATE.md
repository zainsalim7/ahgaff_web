# 👥 تحديث التطبيقين — المجموعات الدراسية داخل المقرر
**إلى:** وكيل تطبيق الطالب + وكيل تطبيق المعلم
**من:** فريق نظام الإدارة (الخادم/الويب)
**التاريخ:** 2026-10-04
**الأولوية:** متوسطة — المنطق يعمل الآن بلا تعديل، والمطلوب إظهار اسم المجموعة في الواجهة فقط.

---

## 1) ما الذي تغيّر في الخادم؟
أضفنا «المجموعات الدراسية داخل المقرر»: طلاب المقرر الواحد قد يُوزَّعون إلى مجموعات (عملي/مختبر) ولكل مجموعة مدرّس اختياري. المحاضرة قد تكون **للشعبة كاملة** أو **لمجموعة محددة**.

### حقول جديدة في كل كائن محاضرة (`/api/lectures/*` و `/api/lectures/{id}/details`)
```json
{
  "group": "1",              // رمز المجموعة — فارغ "" إذا كانت المحاضرة لكل الطلاب
  "group_name": "مجموعة 1"   // الاسم المعروض — فارغ "" إذا لا مجموعة
}
```
الحقلان موجودان دائماً (قد يكونان فارغين). لا تُحذف أي حقول قديمة.

### حقول جديدة في كائن المقرر (`GET /api/courses`)
```json
{
  "groups": [{ "key": "1", "name": "مجموعة 1", "teacher_id": "..." }],
  "group_roles": [{ "key": "1", "name": "مجموعة 1" }]   // للمعلم فقط: المجموعات التي يقودها في هذا المقرر إن لم يكن مدرّس المقرر
}
```

### مسار جديد (اختياري)
- `GET /api/students/{student_id}/groups` → مجموعات الطالب في كل مقرراته:
  `[{ course_id, course_name, course_code, group, group_name }]`
- `GET /api/courses/{course_id}/groups` → تعريف مجموعات المقرر وطلابها (للمعلم إن أردتم شاشة تفصيلية).

## 2) ما يعمل تلقائياً الآن (بلا أي تعديل)
| التطبيق | السلوك |
|---|---|
| الطالب | `GET /api/lectures/{courseId}` يُفلتر من الخادم: يعيد محاضرات الشعبة + محاضرات **مجموعة الطالب فقط**. |
| المعلم | `GET /api/lectures/today` و `/api/lectures/month/{y}/{m}` تشمل محاضرات المجموعات المُسندة له حتى في مقررات ليست له. |
| المعلم | `GET /api/lectures/{id}/details` يعيد **طلاب المجموعة فقط** لمحاضرة مجموعة، و `POST /api/attendance/session` مسموح لمدرّس المجموعة. |
| المعلم | `GET /api/courses` يعيد المقررات التي يقود فيها مجموعة فقط (مع `group_roles`). |
| الاثنان | إشعارات «محاضرة جديدة/غياب» تصل لطلاب المجموعة ومدرّسها فقط. |

⚠️ لا تعتمدوا على تصفية محلية حسب الشعبة — الخادم هو المرجع.

## 3) المطلوب من **تطبيق الطالب** (student-app)
1. **`app/(tabs)/my-schedule.tsx`** — بطاقة المحاضرة: أضف شارة بجوار القاعة عندما يكون `lecture.group` غير فارغ:
   ```tsx
   {lecture.group ? (
     <View style={styles.lectureDetailRow}>
       <Ionicons name="people" size={13} color="rgba(255,255,255,0.8)" />
       <Text style={styles.lectureDetailText}>{lecture.group_name || `مجموعة ${lecture.group}`}</Text>
     </View>
   ) : null}
   ```
2. **`app/(tabs)/my-attendance.tsx`** (اختياري): اعرض `group_name` بجوار اسم المقرر في سجل الحضور إن توفّر في العنصر.
3. **`app/(tabs)/index.tsx` / `calendar.tsx`**: أي مكان يعرض محاضرة → نفس الشارة.
4. **التخزين المؤقت**: إن كانت استجابات `/lectures/*` تُخزَّن محلياً، أفرغوا الكاش عند أول تشغيل بعد التحديث حتى لا تظهر محاضرات مجموعات أخرى من نسخة قديمة.
5. واجهة الأنواع: أضيفوا `group?: string; group_name?: string;` إلى `interface Lecture`.

## 4) المطلوب من **تطبيق المعلم** (teacher-app)
1. **`app/(tabs)/index.tsx`** (محاضرات اليوم): شارة `👥 {group_name}` على بطاقة المحاضرة عندما `item.group` غير فارغ.
2. **`app/(tabs)/my-courses.tsx`**: إذا كان `course.group_roles?.length > 0` اعرض شارة: «تقود {أسماء المجموعات} فقط» — لتوضيح أن المعلم ليس مدرّس المقرر كاملاً.
3. **`app/lecture-attendance.tsx` و `app/(tabs)/take-attendance.tsx`**: في ترويسة الشاشة اعرض `lecture.group_name` بجوار اسم المقرر والقاعة (القائمة التي تعود من `/details` هي طلاب المجموعة فقط — لا تجلبوا طلاب المقرر من مسار آخر).
4. **`app/course-students.tsx`** (اختياري): إن أردتم عرض مجموعة كل طالب استخدموا `GET /api/enrollments/{course_id}` — كل سجل يحوي `group`.
5. **الكاش**: `/lectures/today` ضمن `CACHEABLE` — تأكدوا أن مفتاح الكاش يُبطَل عند تسجيل دخول مستخدم آخر أو عند تغيّر اليوم.
6. واجهة الأنواع: `group?: string; group_name?: string;` في `Lecture`، و `group_roles?: {key:string; name:string}[]` في `Course`.

## 5) النشر
- التطبيقان **لا يستخدمان expo-updates (OTA)** → التعديل يحتاج **إعادة بناء** (EAS Build) ورفع نسخة جديدة:
  - ارفعوا `version` في `app.json` (مثلاً `1.0.0` → `1.1.0`) و `versionCode`/`buildNumber`.
  - Android: APK/AAB عبر EAS، iOS: TestFlight ثم المتجر.
- لا يوجد كسر توافق: النسخ القديمة تستمر بالعمل (الفلترة من الخادم) لكنها لن تعرض اسم المجموعة.

## 6) اختبار القبول
- حساب طالب في مقرر له مجموعتان: يرى محاضرات الشعبة + مجموعته فقط، وتظهر شارة «مجموعة X» عليها.
- حساب معلم مُسند لمجموعة في مقرر ليس له: يظهر المقرر في «مقرراتي» بشارة «تقود مجموعة X فقط»، ومحاضرات اليوم تحوي محاضرة المجموعة، وشاشة التحضير تعرض طلاب المجموعة فقط ويمكنه حفظ الحضور.
- محاضرة بلا مجموعة: لا تظهر أي شارة (الحقلان فارغان).

بيئة الاختبار: نفس عنوان الخادم الحالي. مقرر تجريبي جاهز: `دراسات حضرموت` (course_id `698f0000d803b27aab0120af`) بمجموعتين، وحساب معلم المجموعة 1: `222222 / test1234`.

للاستفسار: راسلوا فريق الخادم مع ذكر اسم المسار ورقم الإصدار.
