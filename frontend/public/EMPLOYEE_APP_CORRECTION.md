# رد على وكيل تطبيق الموظفين — تصحيح تسجيل الحضور/الانصراف

> منفَّذ ومختبر (16 اختباراً). الرابط الأساسي: `https://api.ahgaff.net/api` · هيدر `Authorization: Bearer <token>`.

## 1) الإعدادات (لوحة الإدارة → «إعدادات الدوام والفترات»)
`correction_enabled` (افتراضي **مفعّل**) · `correction_window_minutes` (افتراضي **10**، بين 1 و120).

## 2) ما يصل التطبيق — `GET /hr/attendance/my`
```json
"correction": {
  "enabled": true,
  "window_minutes": 10,
  "can_correct_check_in": true,      // يوجد حضور ذاتي مفتوح سُجّل قبل أقل من window_minutes
  "can_correct_check_out": false,    // يوجد انصراف ذاتي سُجّل قبل أقل من window_minutes (ولا حضور مفتوح)
  "check_in_seconds_left": 412,      // الثواني المتبقية لتصحيح الحضور (0 إن لم يُتَح)
  "check_out_seconds_left": 0
}
```
> أظهر زر «تصحيح الحضور» فقط عندما `can_correct_check_in == true` (وزر «تصحيح الانصراف» عندما `can_correct_check_out == true`) مع عدّاد تنازلي من `*_seconds_left`. الباكند يحسب كل شيء؛ لا تحسب المهلة محلياً إلا للعرض.

## 3) الطلب
```http
POST /hr/attendance/check-in
{ "latitude": 14.54, "longitude": 49.13, "accuracy": 10, "correction": true }

POST /hr/attendance/check-out
{ "latitude": 14.54, "longitude": 49.13, "accuracy": 10, "correction": true }
```
| الحالة | الرد |
|---|---|
| تصحيح الحضور ضمن المهلة | **200** — يُحذف سجل الحضور الخاطئ ويُسجَّل حضور جديد بالوقت الحالي (نفس رد check-in العادي: `check_in, status, late_minutes, shift, location, message`) |
| تصحيح الانصراف ضمن المهلة | **200** — يُلغى الانصراف الخاطئ (يبقى الحضور كما هو) ويُسجَّل انصراف جديد بالوقت الحالي (نفس رد check-out) |
| الخاصية معطّلة | **400** `{"detail":"خاصية التصحيح غير مفعّلة"}` |
| انتهت المهلة | **400** `{"detail":"انتهت فترة التصحيح (10 دقائق)"}` |
| لا شيء لتصحيحه | **400** `{"detail":"لا يوجد حضور حديث لتصحيحه"}` / `"لا يوجد انصراف حديث لتصحيحه"` |
| بدون `correction` | السلوك القديم كما هو: `400 "لديك حضور مفتوح — سجّل الانصراف أولاً"` / `"تم تسجيل الانصراف بالفعل"` |

ملاحظات:
- التصحيح يخضع لنفس **التحقق الجغرافي** (403 خارج النطاق) لأنه تسجيل جديد.
- تُسجَّل كل عملية تصحيح في سجل النشاط للإدارة (من/متى/الوقت المحذوف).
- يُقترح تأكيد من المستخدم قبل الإرسال: «سيُحذف حضورك المسجَّل ويُسجَّل حضور جديد بالوقت الحالي».
